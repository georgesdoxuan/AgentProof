# Pull noir en rotation dans la démonstration MAISON

- Type : modification
- Priorité : bonus
- Auteur : mehdi
- Date : 2026-11-20

## Constat
La capture fournie par Mehdi montre la boutique de démonstration MAISON avec un pull noir statique, intitulé « Pull col rond en laine », à 49,90 €. Mehdi souhaite un vêtement en volume qui tourne et a demandé le dépôt de l'aperçu sur GitHub.

## Demande
Intégrer un pull noir en rotation dans le visuel produit de la démonstration, en conservant la présentation MAISON. Le fichier voisin `maison-pull-3d.html` est un prototype autonome de référence : l'ouvrir dans un navigateur avec accès à Internet et WebGL.

## Comment vérifier
- Le pull tourne ; Pause arrête la rotation et le bouton permet de la reprendre.
- Le glissement permet de tourner le vêtement manuellement.
- Avec la préférence de réduction des animations, la rotation est initialement arrêtée.
- La présentation reste lisible sur mobile.
- L'intégration conserve le scénario existant du bandeau cookies, le panier et les actions de la démo.
- Prévoir un visuel statique si WebGL ou le chargement échoue.

## Détails
L'aperçu utilise un modèle géométrique procédural inspiré de la capture, pas un modèle textile photoréaliste ni une reconstruction exacte. Three.js 0.170.0 est chargé depuis jsDelivr. Il n'effectue aucune commande, aucun paiement et aucun appel aux agents.

Les tailles sont sélectionnables uniquement dans l'aperçu. Le bandeau cookies n'y est pas reproduit ; il doit être conservé dans la démonstration du site. Le prototype ne remplace pas les composants de production et ne doit pas être copié tel quel dans React : prévoir le chargement client, le nettoyage des ressources et la pause hors écran. La syntaxe JavaScript a été vérifiée ; le rendu n'a pas été testé dans les navigateurs de production.

Aucun fichier applicatif ni configuration n'a été modifié pour cette contribution. Intégration à réaliser par Georges selon les consignes du dépôt.
